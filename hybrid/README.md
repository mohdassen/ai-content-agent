# Hybrid Video Engine

Goal: produce premium Arabic technology videos without depending on one paid avatar vendor.

Pipeline:
1. Research/script and timed scene plan.
2. Avatar layer: local LivePortrait-compatible renderer by default; HeyGen fallback/premium.
3. Broadcast graphics layer: Remotion renders deterministic charts, maps, labels and holographic screens.
4. Composer: presenter stays visible while graphics appear beside the presenter.
5. QA blocks empty panels, legacy green templates, paragraph overlays, and numeric claims without a chart/data visual.
6. Delivery after QA only.

Environment target:
- AVATAR_ENGINE=local|heygen
- 1080x1920, 30fps
- Navy/cyan/gold broadcast-tech identity

The first episode plan is `episode.saudi-datacenter.json`.
